# Content templates

Copy a template into the repository root, rename it with a short lowercase filename, and replace every bracketed instruction before publishing. Add the finished page to `search-index.json` and `sitemap.xml`.

- `guide-template.html` includes evidence-basis, author, review date, safety, sources, and related-reading prompts.
- `review-template.html` separates personal testing from research and manufacturer claims.

Never describe an item as tested unless the test setup, exact product, date, and limitations can be documented.
